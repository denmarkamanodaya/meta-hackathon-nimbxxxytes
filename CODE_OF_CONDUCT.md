# Code of Conduct

nimbytes follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming; no harassment, insults or personal attacks; respect
people's privacy, including the people in shared footage. Maintainers may remove comments,
commits or issues that break these rules.

Report a problem privately to the maintainer through GitHub (the profile of the repository
owner), or with a private security advisory if it involves personal data.
