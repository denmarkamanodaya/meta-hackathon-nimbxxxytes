# Tests

Every package keeps its tests next to its code. This folder is the map, and `run-all.sh` runs
them all, the same way CI does (`.github/workflows/ci.yml`, on every push and pull request).

```bash
tests/run-all.sh        # = make gates: fmt, lint, clippy, every test suite, builds, terraform validate
```

All tests are fast and offline: no calls to the Meta models, no cloud, no secrets. Meta API
responses are recorded fixtures; media is tiny and generated by `ffmpeg` inside the test.

| Package | Where | Count | Run alone |
| --- | --- | --- | --- |
| API: unit tests (domain rules, parsers, adapters), plus use cases and handlers against fakes of every port | `#[cfg(test)] mod tests` beside the code in `api/crates/*/src/`, and 28 suites in `api/crates/testkit/tests/` | 1,064 Rust tests | `cd api && cargo test --workspace` |
| API fixtures (recorded Meta API, SAM, Transcribe, ffprobe) | `api/tests/fixtures/` | 35 files | – |
| Web app and Mac app's web layer | `*.test.ts(x)` beside the code in `web/src/` | 187 files | `cd web && npm test` |
| Renderer (Remotion compositions, captions, timeline) | `*.test.ts` in `render/src/` | 14 files | `cd render && npm test` |
| Mac app (drive, sync, cache) | `#[cfg(test)]` in `desktop/src-tauri/src/` | 77 Rust tests | `make gates-desktop` (macOS only; not in CI) |

The suites are written to the repo's testing rules: tests for every Meta call assert the outgoing
request, not only the parsed result, and nothing is skipped or ignored to get green.
